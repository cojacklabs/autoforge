# v0.20.1 Release Readiness

## Acceptance Review

- **Metadata schema:** PASS — project identity metadata has versioned,
  validated lifecycle, capability, freshness, and retention fields.
- **Inspection:** PASS — projects can be listed and shown in text or JSON.
- **Lifecycle controls:** PASS — archive, restore, and mutation safeguards are
  reversible and explicit.
- **Storage diagnostics:** PASS — local `.autoforge` usage includes lifecycle
  and retention context.
- **Prune safety:** PASS — inaccessible entries support a non-mutating dry run.
- **Compatibility:** PASS — legacy metadata receives safe active defaults.
- **Documentation:** PASS — CLI help, reference, progress, and validation docs
  are synchronized.
- **Validation:** PASS — focused metadata, workspace, lifecycle, and project
  command tests pass.

None identified for the v0.20.1 metadata and storage-control scope.

cross-project synchronization, and hosted storage remain deferred to later

versioning preparation.
